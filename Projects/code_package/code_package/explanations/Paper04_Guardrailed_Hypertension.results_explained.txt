7,200 transitions), and the mask cannot close it because the oracle's own policy already satisfies the
guardrail (its unsafe up-titration rate is 0.000; the oracle's model value is identical with and without the

plausibly due to the fallback to the modal logged action in states without a model; we did not trace
individual violations, so this is a hypothesis.
Statistical strength differs by solver. For Monte Carlo the paired reduction is 1.04 ± 0.64 (p = 0.011). For
DP it is 0.31 ± 0.32 (p = 0.084) and for Q-learning 0.30 ± 0.34 (p = 0.118): the point estimates are of the

actions occur in only some data draws. The direction is consistent, the interval for DP and Q-learning
includes zero, and we therefore describe the effect for these two solvers as suggestive rather than
established. We did not adjust for multiple comparisons; adjusting would weaken even the Monte Carlo
result slightly, which should be borne in mind.
Hypotensive months, the outcome that the guardrail is intended to prevent, are rare. Unmasked DP has
0.007 per episode and the guarded version 0.004; for Q-learning the figures are 0.016 and 0.005; for
Monte Carlo 0.089 and 0.050. None of the paired reductions is significant (p = 0.343, p = 0.414 and p =
0.153). So the mask removes the unsafe action reliably, but at this sample size we cannot show that it
removes the downstream harm: the rare outcome needs more evaluation episodes or more replicates to
detect.

7.4 Learning dynamics




Figure 3. Policy value on the oracle MDP during learning (mean over replicates), with the mask off (pale lines) and on
(bold lines). The dashed line is the guardrailed DP optimum on the oracle model.

Figure 3 compares learning curves. Q-learning reaches its plateau by the first checkpoint (4,800 steps), at
2.65 with the mask and 2.49 without; it never approaches the oracle optimum of 3.41, because it is
solving the estimated model, whose optimum differs from the oracle's. Monte Carlo is slower and
plateaus much lower, at 1.56 with the mask and 1.00 without. The plateau is higher with the mask for
both learners (by 0.15 for Q-learning and 0.57 for Monte Carlo) and in the starting value: the value at
step 0 is -11.9 for guarded Q-learning against -13.8 for unguarded, presumably because an exploring
policy that cannot raise the dose at low pressure is less harmful (we did not isolate this). A conventional
convergence statistic would be steps to 90% of the gap between the behaviour policy and the oracle (3.28
on this scale); no learner reached it in any condition, so we do not report one.

Figure 4. Learning curves with the mask on, with ±1 standard deviation bands over replicates; dotted line is the rule's

Figure 4 shows the guarded curves separately, with the rule's model value (2.28) as a dotted line. Both Q-
learning curves sit above the rule on the oracle model, which is consistent with the model prediction that
a learned policy can beat the rule. The simulator tells a different story: Table 3 shows no learned policy
beating the rule in the real dynamics. A related quantity is the optimism gap, the DP policy's value on its
own estimated MDP minus its value on the oracle MDP. It averaged -0.23 ± 0.45 without the mask and -
0.35 ± 0.38 with it; both intervals include zero, so we do not claim a systematic optimism here. Absolute
model values are also not comparable to simulator values, because the oracle MDP treats the 24-month
horizon as a constant termination hazard (see limitations).
